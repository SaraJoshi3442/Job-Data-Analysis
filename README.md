# Job Data Analysis Dashboard

## Project Overview

This Power BI project analyzes job market data to identify trends in salaries, job roles, locations, and required skills. The dashboard provides interactive visualizations that help users explore employment opportunities and understand the current job market.

## Tools Used

* Power BI Desktop
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization

## Skills Demonstrated

* Data Cleaning and Transformation
* Data Modeling
* DAX Measures and Calculations
* Interactive Dashboard Design
* Business Intelligence Reporting
* Data Analysis

## Key Business Questions

1. Which job roles offer the highest salaries?
2. What skills are most in demand?
3. Which locations have the most job opportunities?
4. How do salaries vary across job titles?
5. What trends can be observed in the job market?

## Dashboard Features

* Interactive Slicers
* KPI Cards
* Salary Analysis Visuals
* Skill Demand Analysis
* Job Distribution Charts
* Dynamic Filtering
